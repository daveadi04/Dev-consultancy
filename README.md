# 🌐 Dev Consultancy  

🚀 A modern and responsive consultancy website built with [Next.js](https://nextjs.org), showcasing clean UI, fast performance, and optimized for scalability.  

🔗 **Live Demo:** [dev-consultancy.vercel.app](https://dev-consultancy.vercel.app)  

---

## ✨ Features  

- ⚡ **Next.js 14** – Server-side rendering & static site generation  
- 🎨 **Tailwind CSS** – Modern, responsive, and utility-first styling  
- 🖋️ **Optimized Fonts** – Using [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) with [Geist](https://vercel.com/font)  
- 📱 **Responsive Design** – Works seamlessly on desktop, tablet, and mobile  
- 🚀 **Deployed on Vercel** – Instant previews & production-ready hosting
